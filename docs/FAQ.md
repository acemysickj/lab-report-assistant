# 常见问题（FAQ）

> 没找到答案？在用户群里问，或发邮件至 toby1354213976@163.com。

## 安装与运行

**Q：下载后怎么运行？**
解压 zip，双击「实验报告助手.exe」。首次启动会自动初始化编译环境（导出 PDF 时零等待）。

**Q：弹蓝色窗口说“已保护你的电脑”，运行不了？**
点「更多信息」→「仍要运行」。Beta 版暂未购买代码签名证书，Windows 会给未知发布者提示，属正常现象。

**Q：杀毒软件报毒？**
Beta 未签名可能触发部分杀软的启发式误报。可添加信任后使用；介意者请等待正式签名版本。

## 账号与额度

**Q：不注册账号能用吗？**
可以。在「我的」页把 AI 来源切到「自己的 API Key」（BYOK），填入你的 DeepSeek key 即可使用生成功能，不消耗平台额度，也不需要注册。

**Q：额度怎么充值？**
应用内「我的」页：微信扫码添加运营者，告知注册邮箱与档位，转账后通常 24 小时内到账，点「刷新余额」即可看到。

**Q：余额显示不对/额度没到账？**
先点「我的」页的「刷新余额」（会显示刷新时间）；仍不对，在群里说一声或发邮件，附上注册邮箱。

**Q：一个额度能干什么？**
生成一个报告部分 5 额度、生成一张图表 3 额度；解析模板、检索讲义免费。生成失败会自动退还额度。

## 生成与导出

**Q：生成时一直“正在思考”/等待较久？**
深度推理模式下 AI 会先思考再输出，状态栏会显示「AI 正在思考中…」；普通模式通常几秒内开始出字。等待超过 5 分钟可直接重试，失败不扣额度。

**Q：提示“操作过于频繁”？**
平台限流（并发 2 / 每分钟 10 次 / 每小时 50 次），稍等片刻再试。

**Q：导出 PDF 报错？**
首次导出会自动部署内置 LaTeX 环境（需要几分钟）；部署完成后仍失败，把提示文案发群里。

**Q：换电脑怎么迁移数据？**
设置 → 备份数据，导出 `.labreport` 文件；新电脑上「恢复数据」导入。账号与额度跟邮箱走，登录即可。

## 数据与隐私

**Q：我的报告/讲义会被存到服务器吗？**
不会。讲义、报告、图片不在服务器持久化存储；使用平台 AI 时，仅完成任务所必需的文本经服务器转发给 AI 服务商（DeepSeek）。详见应用内《隐私政策》。
